# Project ORBIT phased plan

1. Hardware selection and purchasing
2. Board bring-up and OLED validation
3. LoRa packet communication
4. Sensor and telemetry integration
5. Ground-station dashboard and data logging
6. Commands, acknowledgements and fault handling
7. Low-power operation and solar power
8. Mission simulation and field testing
9. Documentation, academic report and demonstration

## Current status
Phase 1. Waiting for the Robocraze board delivery. No additional purchase required yet.

## First acceptance criteria
- Board/revision identified
- USB serial connection verified
- Firmware builds for the confirmed board
- Serial output includes `ORBIT-SAT BOOT OK`
- OLED displays the boot message
- SX1262 interface identified and initialization checked without transmission
